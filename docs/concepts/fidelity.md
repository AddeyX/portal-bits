# Fidelity

Recorded measurements are the visual authority for the library.

A measured value was observed and written down. An adaptation covers a gap that was not measured. The gallery and the docs say which is which.

The measured theme is light. A dark control in the gallery is an adaptation.

A declared source variable and the computed style on a component can differ. Reproduce the computed value for that component. Measurements live in the [DOM analysis](../dom-analysis.md).

Typography accepts a consumer-supplied Roobert through a family token. This repo does not ship Roobert font files. Inter and the system stack are the fallback, and the gallery says so.

Motion is part of fidelity. Name the trigger, the properties, the duration, the delay, the easing, and what happens if the animation is interrupted before treating a pattern as measured. Animate listed properties. Add a shared motion token only after observed timings have been compared. Under `prefers-reduced-motion: reduce`, state feedback stays immediate and nonessential movement drops.

The pattern list is the [motion reference](../reference/motion.md).
