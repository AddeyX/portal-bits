# Library and gallery

The library is what a consumer imports. The gallery is how a person inspects it.

Demo content is fictional, and the gallery labels it as demo content. Favorites, filters, and dialogs change local gallery state. The gallery does not talk to a wallet, a chain, or an account service.

A consumer can import components and token CSS without importing a route or `src/demo`.
