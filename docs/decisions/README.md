# Decisions

Git records what changed. An ADR records why.

Name a decision `NNNN-kebab-title.md`. Example: `0001-one-sveltekit-repository.md`.

Each file has:

- **Status** — Proposed, Accepted, or Superseded
- **Context** — what problem existed
- **Decision** — what we chose
- **Consequences** — what becomes easier, and what becomes harder

Add a numbered file when a real decision is made.
